# Gemma 4 live transcription — план работ

Ветка: `claude/vlc-gemma-transcription-secqt1`, PR: https://github.com/usr1c83/vlc/pull/1

## Сделано

- [x] Аудиофильтр `gemma_transcribe`: транскрибация/перевод речи налету (Gemma 4).
- [x] Sub source `transcript`: живые субтитры поверх видео.
- [x] Бэкенды инференса: встроенный (llama.cpp/libmtmd, GGUF локально),
      OpenAI-совместимый сервер, Google Generative Language API.
- [x] Закадровая озвучка по ролям (диаризация S1/S2), приглушение оригинала.
- [x] Синтез речи: встроенный espeak-ng (голоса по языку) или OpenAI TTS-сервер.
- [x] Все опции доступны в GUI (Настройки → Все → Аудио → Фильтры → Gemma transcribe).
- [x] Сборка autotools + meson, определение зависимостей в configure.
- [x] Полная сборка и сквозные тесты (заглушка сервера, проверка пикселей
      субтитров, замер приглушения при озвучке), фикс бага rawvid/Y4M.
- [x] Подписка на события PR (CI, ревью) + периодическая самопроверка.

## В работе

- [x] Автозагрузка весов модели с Hugging Face из GUI: поиск весов
      (опция → комплект поставки → каталог пользователя → скачивание
      с прогресс-диалогом). Файл: `modules/audio_filter/transcribe/download.c`.
      Модель по умолчанию: `unsloth/gemma-4-E2B-it-GGUF` (Q4_K_M, ~3.1 ГБ)
      + `mmproj-F16.gguf`.
- [x] Экспорт субтитров в SRT: `--gemma-transcribe-export-file` (таймкоды
      по PTS сегментов).
- [x] Экспорт аудиоперевода в WAV: `--gemma-transcribe-export-audio`
      (дорожка озвучки, выровненная по таймлайну).
- [x] Режим прослушивания системного звука: `--gemma-transcribe-listen` —
      VLC слушает монитор аудиовыхода (pulse/wasapi), выводит только
      перевод (озвучку + субтитры), оригинал не дублирует. Пример:
      `vlc pulse://<sink>.monitor --audio-filter=gemma_transcribe
       --gemma-transcribe-listen --gemma-transcribe-voiceover`.
- [x] GitHub Actions: автосборка релизов — ГОТОВО. Первый релиз:
      https://github.com/usr1c83/vlc/releases/tag/dev-7 (Linux tar.zst
      2 части, Windows 7z 2 тома, все < 2 ГиБ, веса E2B Q4_K_M + mmproj
      вшиты, SHA256SUMS). Запуск: тег vX.Y.Z (полный релиз) или вручную
      workflow_dispatch (prerelease dev-N). PR-прогоны собирают с
      весами-заглушками для быстрой отладки.

- [x] Дружелюбный GUI: расширение «Live Translation (Gemma 4)» в меню
      View. Диалог: язык, субтитры/озвучка, кнопка Translate — включает
      перевод для текущего видео одним кликом, без серверов и без
      копания в настройках. Файл:
      `share/lua/extensions/gemma_translate.lua`. Загрузчик модели теперь
      сразу даёт понятную ошибку вместо 10 повторов, если сети нет.
      README в релизе ведёт с меню, поля «Inference server» (8080/8880)
      помечены как необязательные.

- [x] GPU-ускорение и производительность: опция
      `--gemma-transcribe-gpu-layers` (по умолчанию -1 — выгрузить всю
      модель на GPU, когда он есть; 0 — только CPU). В llama.c задаются
      `n_gpu_layers` и `mtmd use_gpu`; если в сборке нет GPU-бэкенда,
      автоматически откат на CPU с предупреждением. В меню перевода —
      галочка «Use the GPU». В CI llama.cpp собирается с Vulkan
      (кросс-вендор: NVIDIA/AMD/Intel) для Linux и Windows, загрузчик
      Vulkan вшивается в пакет, при отсутствии GPU — прозрачный откат на
      CPU. Конвейер инференса теперь держит только новейшие сегменты
      (drop-oldest, глубина `MAX_PENDING`): субтитры и озвучка не
      «уплывают» всё дальше от видео, когда CPU не успевает, а
      отбрасывают промежуток. Проверено: юнит-тест очереди на настоящем
      `vlc_queue` (глубина ограничена, отбрасываются старые, остаются
      новые), регистрация опции в GUI, сборка/линковка плагина.

## Отложено / заметки

- Contrib-рецепты для llama.cpp и espeak-ng (официальная упаковка
  VideoLAN) — из песочницы недоступны канонические tarball'ы для SHA512;
  в CI-релизах зависимости собираются напрямую из клонов по пинованному тегу.
- espeak-ng — GPLv3+: при апстриминге в VideoLAN обсудить лицензию
  (сам плагин LGPL 2.1+, линковка опциональна).
- Локальный инференс проверен по сборке/линковке и API; первый прогон с
  реальными весами Gemma 4 — на машине с местом под модель.
- Диаризация консистентна внутри сегмента; сквозная нумерация говорящих
  между сегментами — возможное улучшение (контекст предыдущего сегмента
  в промпте).
- Ducking чужих приложений (реальное приглушение браузера) — возможно
  через PulseAudio/WASAPI session API; в текущем режиме listen VLC просто
  не дублирует оригинал.
